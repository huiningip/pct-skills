## التثبيت

### الطريقة 1: سكربت المزامنة (موصى به)

```bash
# Windows
py -3 scripts/sync_to_local.py

# macOS / Linux
python3 scripts/sync_to_local.py

# خيارات شائعة
py -3 scripts/sync_to_local.py --dry-run                    # معاينة دون كتابة
py -3 scripts/sync_to_local.py --target D:/path/to/skills   # مجلد مهارات مخصص
```

يقوم السكربت بمزامنة المهارات الست في `skills/` إلى مجلد المهارات المحلي (افتراضيًا `~/.workbuddy/skills`) باتجاه واحد: تُستبدل الملفات الجديدة أو المعدّلة، وتُحذف الملفات القديمة، مع **الحفاظ تلقائيًا على البيانات الوصفية المحلية (مثل `_user_meta.json`)**.

### الطريقة 2: النسخ اليدوي

انسخ مجلدات المهارات المطلوبة من `skills/` إلى مجلد المهارات لديك (مثل `~/.workbuddy/skills/`)، ثم أعد تشغيل التطبيق أو أعد تحميله.

> ⚠️ هذه مجموعة متعددة الملفات: النصوص الطويلة في `references/` (المعاهدة، اللائحة التنفيذية، التعليمات الإدارية، معايير البحث والفحص، إلخ) تُستدعى من `SKILL.md` عبر مسارات `@` نسبية — **فقدان ملف واحد يقطع السلسلة**. انسخ المجلدات كاملة، ولا تأخذ `SKILL.md` وحده.

## ما الذي يقدمه

| المهارة | الدور | الوصف |
|------|------|------|
| [`pct-guide`](skills/pct-guide) | المهارة الأم | مركز التوجيه: يوزّع السؤال على المجالات الخمسة وينسّق بين المهارات |
| [`pct-treaty`](skills/pct-treaty) | طبقة المصادر القانونية | المعاهدة واللائحة التنفيذية وجداول الرسوم والتصريحات والتحفظات — الأساس القانوني للأسرة |
| [`pct-international-phase`](skills/pct-international-phase) | المرحلة الدولية | الإيداع، المعالجة، البحث، النشر، تعديلات المادة 19، الفحص التمهيدي للفصل الثاني |
| [`pct-national-phase`](skills/pct-national-phase) | المرحلة الوطنية | مواعيد وإجراءات الدخول، استعادة الحقوق، PPH والإجراءات اللاحقة |
| [`pct-search-examination`](skills/pct-search-examination) | البحث والفحص | قراءة تقرير البحث الدولي / الرأي المكتوب / التقرير التمهيدي الدولي، الحد الأدنى من الوثائق، وحدة الاختراع |
| [`pct-administrative`](skills/pct-administrative) | الإجراءات والنماذج | التعليمات الإدارية (AI)، دليل المكتب المستقبل، ePCT والنماذج |

## الآليات الأساسية

1. **التوجيه عبر المهارة الأم**: اطرح السؤال من أي مدخل — يحدد `pct-guide` المجال أولًا، ثم يستدعي المهارة الفرعية المناسبة؛
2. **مصدر قانوني بنقطة واحدة**: تتركز البيانات الديناميكية (أحكام المعاهدة، اللائحة، الرسوم) في `pct-treaty`، ما يمنع تباين الأرقام بين المواضع المختلفة؛
3. **الكشف التدريجي**: تعيش النصوص الطويلة في `references/` وتُحمَّل عند الحاجة دون إثقال السياق؛
4. **«لا يوجد» بدلًا من الاختلاق**: تُوسم المعلومات غير المؤكدة مباشرة — لا اختراع لأي أحكام أو مواعيد أو أرقام رسوم.

## البيانات ومصادرها

- تتبع المصادر القانونية **أحدث النسخ الرسمية للمنظمة العالمية للملكية الفكرية (WIPO) / CNIPA**؛ ويُسجَّل في كل مهارة تاريخ أساس المصادر؛
- للبيانات المتغيرة (الرسوم، المواعيد)، أعد التحقق من أحدث الإعلانات الرسمية قبل استخدامها في الملف؛
- المخرجات مرجع عملي — **وليست رأيًا قانونيًا**.

## الحدود والقيود

- لا تُغني عن الجهات الرسمية ولا عن التقدير في كل حالة بعينها: المواعيد والرسوم والنتائج الإجرائية تخضع لإشعارات المكتب المستقبل والإعلانات الرسمية؛
- لا اختلاق: البيانات غير الموجودة تُجاب بـ«لا يوجد»؛
- يتركز التغطية القانونية على معاهدة PCT والطبقة الإجرائية؛ أما القانون الموضوعي والممارسة الفحصية لكل مكتب معيّن فتخضع للموقف الرسمي لذلك المكتب.
