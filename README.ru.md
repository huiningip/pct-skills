**Практический набор навыков для полного цикла международной заявки PCT — родительский навык + 5 дочерних навыков — для патентных поверенных, корпоративных IP-команд и заявителей, работающих за рубежом.**

<br>

Это не популярный ликбез: маршруты проверки процедур и сроков, правовые источники с проверкой по пунктам, методика чтения выводов поиска и экспертизы, а также формальности входа в национальную фазу и восстановления прав.

Основано на универсальном формате Agent Skills (`<skill-name>/SKILL.md`); работает с любым агентом, поддерживающим skills.

## Установка

### Способ 1: скрипт синхронизации (рекомендуется)

```bash
# Windows
py -3 scripts/sync_to_local.py

# macOS / Linux
python3 scripts/sync_to_local.py

# Частые параметры
py -3 scripts/sync_to_local.py --dry-run                    # предпросмотр, без записи
py -3 scripts/sync_to_local.py --target D:/path/to/skills   # свой каталог навыков
```

Скрипт односторонне синхронизирует 6 навыков из `skills/` в локальный каталог навыков (по умолчанию `~/.workbuddy/skills`): новые и изменённые файлы перезаписываются, устаревшие удаляются, а **локальные метаданные (`_user_meta.json` и т. п.) сохраняются**.

### Способ 2: ручное копирование

Скопируйте нужные каталоги навыков из `skills/` в свой каталог навыков (например, `~/.workbuddy/skills/`), затем перезапустите приложение или перезагрузите его.

> ⚠️ Это набор из множества файлов: объёмные тексты в `references/` (Договор PCT, Инструкция, Административная инструкция, стандарты поиска и экспертизы и т. д.) подключаются из `SKILL.md` по относительным `@`-путям — **отсутствие одного файла разрывает цепочку**. Копируйте каталоги целиком, не берите только `SKILL.md`.

## Что он умеет

| Навык | Роль | Описание |
|------|------|------|
| [`pct-guide`](skills/pct-guide) | Родительский навык | Хаб маршрутизации: определяет область вопроса из пяти и координирует навыки |
| [`pct-treaty`](skills/pct-treaty) | Слой правовых источников | Договор PCT и Инструкция, тарифы пошлин, заявления и оговорки — правовая основа семейства |
| [`pct-international-phase`](skills/pct-international-phase) | Международная фаза | Подача, обработка, поиск, публикация, поправки по статье 19, предварительная экспертиза главы II |
| [`pct-national-phase`](skills/pct-national-phase) | Национальная фаза | Сроки и формальности входа, восстановление прав, PPH и последующие процедуры |
| [`pct-search-examination`](skills/pct-search-examination) | Поиск и экспертиза | Чтение ISR / письменного мнения / IPER, минимум документации, единство изобретения |
| [`pct-administrative`](skills/pct-administrative) | Формальности | Административная инструкция (AI), руководство получающего ведомства, ePCT и формы |

## Ключевые механизмы

1. **Маршрутизация через родительский навык**: задайте вопрос с любой точки входа — сначала `pct-guide` определит область, затем вызовет соответствующий дочерний навык;
2. **Единый источник права**: динамические данные (положения Договора, Инструкция, пошлины) сведены в `pct-treaty`, что исключает расхождения цифр в разных местах;
3. **Постепенное раскрытие**: объёмные тексты лежат в `references/` и загружаются по мере необходимости, не перегружая контекст;
4. **«Нет» вместо вымысла**: недостоверная информация прямо помечается — никаких выдуманных положений, сроков или сумм.

├── skills/                    # 6 навыков (1 родительский + 5 дочерних)

- Файлы навыков: **CRLF, UTF-8 без BOM**.

## Данные и происхождение

- Правовые источники — по **действующим официальным версиям ВОИС / CNIPA**; в каждом навыке указана дата актуальности источников;
- Для изменчивых данных (пошлины, сроки) перед использованием в деле сверяйтесь с последними официальными публикациями;
- Выводы носят справочно-практический характер и **не являются юридическим заключением**.

## Область применения и ограничения

- Не заменяет официальные инстанции и оценку по конкретному делу: сроки, пошлины и процедурные выводы определяются уведомлениями получающего ведомства и официальными публикациями;
- Никакого вымысла: ненайденные данные возвращаются как «нет»;
- Правовой охват — Договор PCT и процедурный уровень; материальное право и практика экспертизы каждого указанного ведомства — по его официальной позиции.
