# PCT国际阶段全流程实务

## 角色

本技能是 **PCT 国际阶段全流程实务子技能**，隶属 `pct-guide` 母技能。从申请人/代理人视角，覆盖 PCT 国际申请从提交到国际公布、国际初步审查的完整国际阶段。

**国际化定位（双板块）**：
- **主体｜国际阶段通用（各缔约国一致）**：提交、受理局处理、检索、公布与第 II 章程序对**任一国籍／任一受理局**的申请人通用，无需中国语境。
- **可选｜特定主管局补充材料**：CNIPA 官方实务问答（附录 A/B）为**中国视角的可选补充**，非中国业务可跳过；PATENTSCOPE 与 ISA/IPEA 协议名录（附录 C/D）为国际通用工具材料。

## 任务

- 指导 PCT 国际申请的提交（请求书 10 栏填写、文件要求、语言、费用）。
- 跟踪受理局处理（申请日确定、缺陷改正、语言检查、费用审查、援引加入）。
- 解读国际检索结果（ISR + WO/ISA、引用分类 X/Y/A/P/O/T/E/D/L/&，共 9 类）与单一性处理。
- 管理国际公布（18个月自动公布、提前公布、保密请求、临时保护）。
- 支持修改与第 II 章决策（Art.19 修改、Art.34 修改、IPEA/401 要求书、IPER）。
- 处理其他事项（代理人/共同代表/变更/更正/撤回/第三方意见/生物材料保藏）。
- 提供国际阶段实务补充（CNIPA 官方 FAQ、EPO 试点、PATENTSCOPE、ISA/IPEA 协议）。
- 向用户交付**符合输出格式规范**的分析结论。

## 上下文（背景数据）

- 依据《PCT申请人指南-国际阶段》（2025年9月4日更新），从申请人视角全面覆盖国际阶段。
- 核心流程：提交国际申请 → 受理局检查 → 国际检索（ISR+WO/ISA）→ 国际公布（18个月）→（可选）国际初步审查（IPER）→ 进入国家阶段（见 `pct-national-phase`）。
- **申请日要件（Art.11(1)，三组）**：①**申请人资格**——不因居所或国籍的原因而明显缺乏向受理局提出国际申请的权利；②**语言**——国际申请用规定的语言撰写；③**最低内容五项**——(a) 说明是作为国际申请提出的、(b) 至少指定一个缔约国、(c) 按规定方式写明的申请人姓名或名称、(d) 有一部分表面上看像是说明书、(e) 有一部分表面上看像是一项或几项权利要求。
    - ⚠️ **费用缴纳不是申请日要件**：传送费／国际申请费／检索费属 Art.14(3) 及细则 Rules 14–16 的范围；未在允许期限内缴纳的后果是**国际申请被视为撤回**（Art.14(3)(a)），既不影响国际申请日的给予，也不导致申请日后移。
    - 不符合上述要件时，受理局按细则要求申请人改正；**以收到必要改正之日为国际申请日**（Art.11(2)）。
- **默认全部指定**（Rule 4.9）：提交即指定所有 PCT 缔约国。
- **关键选择点**：是否请求补充检索；是否进入第 II 章（优先权日起 22 个月内决定）。
- **费用构成**：传送费（受理局）+ 国际申请费（国际局）+ 检索费（ISA）+ 可选补充检索费 + 可选初步审查费。
- **联动**：`pct-administrative`（ST.26 序列表、ePCT、费用、表格 PCT/RO/102·132·133、PCT/IPEA/401）；`pct-search-examination`（ISR 解读、ISPE 标准）；`pct-national-phase`（进入国家阶段）。

## 流程（步骤）

1. **确认申请人资格**：是否 PCT 缔约国居民/国民，确定受理局与 ISA 选择范围。
2. **准备申请文件**：请求书 + 说明书 + 权利要求 + 附图（如有）+ 摘要 + 序列表（ST.26，如涉及）+ 生物材料保藏（如涉及）。
3. **提交申请**：确认受理局 + 语言 + 费用足额，取得国际申请日。
4. **跟踪国际检索**：关注 ISR + WO/ISA（约申请日后 4-6 个月），解读 X/Y/A 分类与单一性意见。
5. **决定是否修改**：ISR 结果 → Art.19 修改（仅权利要求）或进入第 II 章（Art.34 全面修改）。
6. **处理国际公布**：确认公布信息 / 提前公布请求 / 保密请求 / 临时保护监控。
7. **进入第 II 章（可选）**：22 个月内提交要求书 → IPEA 审查 → 28 个月出 IPER。
8. **准备进入国家阶段**：确定进入国 / 准备译文 / 准备费用（转 `pct-national-phase`）。

> 🔴 **CHECKPOINT（步骤4-5，最关键决策点）**：ISR 结果出来后须同时评估：ISR 正面 → 无需第 II 章；ISR 负面 → 评估第 II 章性价比；单一性问题 → 决定缴费或放弃非主发明组。

## 规则（约束/边界）

1. **PCT 国际阶段不授权**：国际检索/初步审查仅提供意见，对各国无约束力，不得表述为"授权"。
2. **Art.19 vs Art.34 修改**：Art.19 仅限权利要求（ISR 送达日起 2 个月或优先权日起 16 个月，以晚者为准）；Art.34 可改权利要求+说明书+附图（第 II 章程序中）。
3. **语言匹配**：申请语言必须同时符合受理局与 ISA 的语言要求；英文最通用。
4. **单一性处理**：发现单一性问题时，评估各发明组价值后再决定是否缴附加费，勿一律缴费。
5. **援引加入时效**：须在申请日后规定期限内提出，且遗漏部分须包含在优先权文件中。
6. **序列表 ST.26**：2022-07-01 起须用 ST.26 XML 格式；2026 年起序列表不计入计费页数（免附加费）。
7. **费用减免**：ePCT 电子提交可享国际申请费减免；金额以 WIPO 当期费用表为准。
8. **期限输出**：无优先权日只输出期限长度与起算规则，不输出具体日期。
9. **费用金额动态性（EPO 试点）**：EPO 检索费欧元值（现行 1845 欧元）与人民币代收基准值（14870 元，2026-08-01 起）均为动态值，使用前以 EPO RFees / WIPO 当期人民币标准复核，勿套用历史金额；14870 元仅适用于中欧 PCT 试点国际阶段，非欧洲地区阶段费用。
10. **PATENTSCOPE ≠ ePCT**：前者是公开检索数据库，后者是提交办理门户（属 `pct-administrative`）。
11. **输出硬约束（对用户交付文本）**：
    - **严禁输出任何 Markdown 表格**；
    - **如果找不到数据，直接回复"无"，严禁编造**。
12. 本技能内部知识库（参考/指引内容）不受第 11 条"禁表格"约束，可保留 Markdown 表格作为知识载体。

### 第1章：PCT体系概述

| 概念 | 说明 |
|------|------|
| PCT是什么 | 1970年华盛顿签订、WIPO管理的国际条约，简化多国专利申请 |
| 国际阶段 vs 国家阶段 | 国际阶段=统一受理/检索/公布/初审；国家阶段=各国独立审查/授权 |

### 第2章：国际申请的提交

#### 请求书（10个栏目）填写

| 栏目 | 内容 | 注意事项 |
|------|------|---------|
| 第I栏 | 申请人 | 姓名/地址/国籍/居所/电话号码等 |
| 第II栏 | 受理局（根据申请人资格确定） | 由申请人国籍/居所决定；符合条件时可在可选受理局中选择 |
| 第III栏 | 发明人 | 姓名/地址(注意AI不能作为发明人) |
| 第IV栏 | 代理人/共同代表 | 如需委托代理人 |
| 第V栏 | 国家指定 | 默认全部指定(Rule 4.9) |
| 第VI栏 | 优先权声明 | 在先申请日/号/国(需12个月内) |
| 第VII栏 | 国际检索单位(ISA) | 从可选ISA中选择 |
| 第VIII栏 | 权利要求项数 | 超项附加费计算 |
| 第IX栏 | 摘要 | 约150字技术摘要 |
| 第X栏 | 签字 | 申请人或代理人签署 |

> **🔴 CHECKPOINT**：提交前须核对：第VI栏优先权日是否在12个月内；第VII栏ISA是否接受申请语言；费用是否足额缴纳。

#### 申请文件要求

| 文件 | 要求 |
|------|------|
| 说明书 | 清楚完整公开发明，使本领域技术人员能实施 |
| 权利要求 | 定义保护范围，以说明书为依据 |
| 附图 | 理解发明必需的(如适用) |
| 摘要 | 技术信息摘要，约150字 |
| 序列表 | 如涉及核苷酸/氨基酸序列，需ST.26格式 |
| 生物材料保藏 | 如涉及，需在申请日前或同日完成 |

#### 申请语言

> 各受理局和 ISA 接受的语言不同。英文为最通用选择。申请语言必须符合受理局和 ISA 双方的语言要求。

### 第3章：受理局处理

| 处理事项 | 说明 |
|---------|------|
| **申请日检查(Art.11(1))** | ①申请人资格（不因居所／国籍明显缺乏申请权）②使用规定语言 ③最低内容五项：说明为国际申请＋至少指定一国＋申请人姓名或名称＋表面像说明书的部分＋表面像权利要求的部分（**不含费用**） |
| **缺陷改正** | 缺少部分/错误提交项目→援引加入程序 |
| **语言检查** | 申请语言须符合受理局和ISA要求 |
| **费用审查** | 传送费+国际申请费+检索费是否足额缴纳 |
| **申请日确认** | 满足条件→通知申请人和国际局 |

#### 援引加入

允许在申请日之后补充说明书/权利要求/附图中的项目或部分，条件是：
- 首次提交中存在遗漏
- 在优先权文件中包含
- 在规定期限内提出请求

### 第4章：国际检索

| 事项 | 说明 |
|------|------|
| **ISR内容** | X/Y/A类引用文献、P/O类文献、发明单一性意见 |
| **WO/ISA内容** | 可专利性意见(新颖性/创造性/实用性) |
| **单一性处理** | 发现单一性问题→ISA邀请缴纳附加费→可选择缴费或放弃 |
| **序列表检索** | 如涉及，需ST.26格式电子文件 |
| **补充检索(可选)** | 可在ISR后请求第二ISA补充检索 |

#### 引用分类（九类：X / Y / A / P / O / T / E / D / L / &）

| 分类 | 含义 |
|------|------|
| X | 单独使用即可否定新颖性或创造性 |
| Y | 与其他文献结合否定创造性 |
| A | 背景技术文献 |
| P | **中间文献**：公布日落在**优先权日与国际申请日之间**的文献（含与最早优先权日同日公布者）；须与 X/Y/A 组合标注（P,X ／ P,Y ／ P,A）—— ISPE §16.71 |
| O | 非书面公开(口头/使用/展览等)；须与 X/Y/A 组合标注（O,X ／ O,Y ／ O,A）—— ISPE §16.70 |
| T | **理论／原理文献**：公布日晚于申请日或优先权日，但有助于理解发明所依据的原理或理论，或用以表明发明的推理／事实有误 —— ISPE §16.72 |
| E | **潜在冲突的专利文献**：申请日或优先日早于本申请的国际申请日、但在国际申请日当日或之后公布的文献（依 Rule 33.1(c)）；可组合 E,X ／ E,Y ／ E,A —— ISPE §16.73 |
| D | **申请中已引证的文献**：说明书或检索报告中已引用的文献；须与 X/Y/A 组合标注（D,X ／ D,Y ／ D,A）—— ISPE §16.74 |
| L | **其他理由引证**：如用以质疑优先权主张（巴黎公约 Art.4(C)(4)）、或确立另一引证的公布日等证据性引用 —— ISPE §16.75 |
| & | **同一专利族文献**：相同发明在不同国家／地区的公布 |

### 决策矩阵（关键选择点）

#### ISA 选择决策矩阵

| 条件 | 推荐 ISA | 理由 |
|------|---------|------|
| 中文申请 / 主要进入中国 | CNIPA | 语言匹配（中文），中国国际阶段审查参考直接可用 |
| 主要进入欧洲(EPO) | EPO | 欧洲审查意见参考、英/法/德语言衔接 |
| 主要进入美国(USPTO) | USPTO | 美国审查意见参考，避免二次检索 |
| 化学/生物领域且进入多国 | EPO 或 CNIPA | 两局检索质量高、引文体系完善 |
| 成本优先（检索费敏感） | 比较各可选ISA检索费后选最低 | 传送费/申请费固定，检索费各局不同 |

#### 第II章进入决策矩阵

| ISR/WO-ISA 结果 | 动作 | 理由 |
|----------------|------|------|
| 正面（无X/Y或意见有利） | 跳过第II章，直接进入国家阶段 | 节省初步审查费与时间 |
| 负面（存在X/Y引用） | 预算充足→提交要求书(IPEA/401)；预算紧→国家阶段再争辩 | 第II章有机会陈述意见、争取有利IPER |
| 单一性问题且有分案价值 | 缴附加费保留全发明组，或分案进入国家阶段 | 避免非主发明组被限制检索 |
| 目标国重视IPER | 进入第II章 | IPER 对该国审查有参考价值 |

### 实务要点

1. **ISA选择策略**：不同ISA的检索质量/语言/费用/标准不同（EPO/CNIPA/USPTO/KIPO/JPO等），根据技术领域和后续国家阶段选择。
2. **补充检索价值**：如目标国家为某 ISA 所在国，补充检索可提前获得该国审查意见参考。
3. **第II章决策**：基于 ISR 质量决定是否进入第 II 章；ISR 已正面 → 无需第 II 章可节省费用；ISR 负面或不确定 → 第 II 章有机会陈述意见。
4. **语言选择**：以英文提交可最大化后续国家阶段灵活性；中文申请 → 指定 CNIPA 为 ISA。
5. **费用缴纳策略**：ePCT 电子提交享费用减免；时刻关注费用表更新。
6. **序列表准备**：现行细则对序列表格式和费用有新规定（符合 ST.26 不计入计费页数、免附加费）。

### 失败模式与恢复

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 申请人资格不符合PCT缔约国要求 | 核查申请人国籍/居所→找符合条件的共同申请人→变更申请人 | 考虑巴黎公约途径提交各国申请 |
| 申请文件缺少说明书或权利要求 | 后续补交→申请日后移 | 评估申请日后移对优先权的影响→必要时重新提交 |
| 援引加入请求超过期限 | 检查是否在优先权文件中包含遗漏部分→联系受理局 | 无法援引→原始申请日为准 |
| ISA发出单一性附加费邀请（不愿缴费） | 评估发明组是否确实无单一性 | 仅保留主发明组→可分案进入国家阶段 |
| ISR结果负面（X/Y类文献引用） | 分析X/Y文献是否可区分/争辩→决策Art.19修改或第II章 | 直接进入国家阶段并在该阶段争辩 |
| 第II章要求书超过22个月期限 | 确认是否有宽限期/恢复可能 | 无法进入第II章→直接进入国家阶段 |
| 费用未足额缴纳 | 受理局发出缴费通知（Form PCT/RO/102）→在指定期限内补缴；必要时可依细则 Rule 16bis 请求延长期限 | 未补缴→**国际申请视为撤回**（**Art.14(3)(a)**，由受理局作相应宣告）。注：PCT 细则**不存在 Rule 16ter**，原引有误 |
| 补充检索(SISA)结果与主ISA检索结论冲突 | 综合分析两份检索报告→标注引文冲突点和结论差异 | 优先采用覆盖范围更广或日期更早的检索结果→附注说明差异原因 |
| 序列表ST.26格式未在申请时提交 | 在受理局规定的补充期限内提交ST.26 XML格式文件 | 超期未提交→申请可能被视为不完整，需重新提交申请 |
| 国际公布后发现申请文件有重大错误 | 在国际公布后通过规则91明显错误更正程序更正 | 无法通过Rule 91更正→在国家阶段提交修改申请 |
| 第三方意见在国际公布前提交 | 确认第三方观察窗口＝**国际公布日至优先权日起 28 个月**（《PCT行政规程》Section 802(a)(ii)） | 窗口未开放→等待国际公布后再提交 |

### 禁止行为与反例

| # | 禁止行为 | 原因 | 正确做法 |
|---|---|---|---|
| 1 | 不经评估随意选择ISA | ISA选择影响检索质量和后续国家阶段策略 | 根据技术领域、语言、后续进入国综合推荐 |
| 2 | 忽视申请语言与ISA语言要求的匹配 | 语言不匹配会导致ISA拒绝受理 | 先确认目标ISA接受的语言再选择申请语言 |
| 3 | 将PCT国际阶段与中国专利审查混为一谈 | PCT国际阶段不授权，仅提供检索/初审意见 | 明确告知：国际阶段意见对各国无约束力 |
| 4 | 漏告Art.19修改和Art.34修改的区别 | 两种修改范围不同、时机不同 | 明确告知：Art.19仅改权利要求；Art.34可改全部文件 |
| 5 | 单一性附加费一律要求缴费 | 某些情况下放弃非主发明组更经济 | 评估各发明组价值→有分案价值才缴费 |
| 6 | 忽略ePCT电子申请费用减免可能性 | ePCT提交可享受国际申请费减免，漏报可导致费用估算偏高 | 优先推荐ePCT电子提交→查询最新减免比例→输出减免后费用 |
| 7 | 不提醒用户在第II章要求书提交后做后续跟踪 | IPEA可能在审查中要求补充材料或答复，不理睬可导致程序终止 | 建立第II章跟踪计划：收到IPEA通知→按时答复→关注IPER制定时间(28个月) |
| 8 | 国际公布前未告知申请人临时保护效力 | 国际公布后申请人在指定国获得临时保护权利，漏告可能导致申请人权益受损 | 在公布前告知各国临时保护规定差异→应监控公布日→准备相关证据 |
| 9 | 交付文本使用 Markdown 表格 | 违反输出格式硬约束 | 用标题 + 列表组织交付文本 |
| 10 | 数据缺失时编造或推测 | 违反"无数据回'无'"硬约束 | 直接回复"无"，并提示可补充的检索途径 |
