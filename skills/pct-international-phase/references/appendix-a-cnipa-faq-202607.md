# 附录A：PCT国际阶段常见问题解答（CNIPA官方，2026年7月）

> 来源：国家知识产权局《PCT国际阶段近期常见问题解答汇总（2026年7月）》。作为国际阶段提交实务的补充参考；涉及序列表 ST.26、ePCT 电子提交/离线客户端权限的细节，交叉参见 `pct-administrative`。

**Q1：电子形式提交 PCT 国际申请包含超大序列表时，无法预览或上传显示"转换 PDF 报错"异常，怎么办？**

A：序列表超大（通常超 2 万条序列时 WIPO 序列表套件不支持预览）导致无法预览或"转换 PDF 报错"，不宜直接认定为提交失败，可尝试继续提交。
- 若案件提交成功：收到回执后①核查回执中是否记载正确大小的序列表；②检查已提交案卷包是否含完整 ST.26 格式序列表。两者均未包含则说明序列表未成功提交，应通过 PCT 国际中间文件——后提交申请文件及时补交序列表（注意补交时间可能导致国际申请日重新认定）。
- 若回执中含序列表：及时联系 PCT 受理局审查员（拨 010-62356655 转 PCT 受理局审查员）核实系统中序列表是否成功提交、数据是否正常显示。
- 若多次尝试仍无法提交成功且无法收到回执：及时联系 010-62356655 寻求技术支持。

**Q2：电子序列表无法预览，是否影响 PCT 国际申请正常提交？**

A：通常不影响提交。无法预览原因可能包括本地硬件条件、提交端显示能力限制，或 WIPO 套件对超大序列表预览支持不足（超 2 万条序列）。如已成功提交并取得回执，先联系审查员确认系统数据，不建议仅因前端无法预览就改为纸件提交。

**Q3：确需纸件提交 PCT 国际申请且同时含序列表，序列表是否计入计费页数？**

A：以光盘方式提交符合 WIPO ST.26 标准的 XML 格式序列表，满足该格式要求的不计入国际申请文件计费页数。
- 若序列表不符合 ST.26 标准且作为国际申请文件一部分提交：需补交符合标准的 XML 格式序列表，申请日以受理局收到该序列表之日为准；否则该序列表计入计费页数，同时需补交用于国际检索目的的电子格式序列表。

**Q4：通过电子方式提交的 PCT 国际申请，非本案件权限人能通过电子方式提交什么类型文件？**

A：非本案件权限人可通过电子方式提交的中间文件类型仅限：著录项目变更请求和初审要求书；其他类型文件无权限通过电子方式提交。

**Q5：使用离线客户端提交 PCT 国际阶段著录项目变更请求时，为何提示没有本案件提交权限？**

A：使用离线客户端提交需以扫码方式登录方可获得完整文件提交权限；若以账号密码方式登录则无法获得完整提交权限。建议扫码重新登录后再提交。

**Q6：使用离线客户端办理 PCT 国际阶段中间文件业务时，为何提示无法查询到本案件？**

A：离线客户端需本地存储相应案件的案卷包方可查询到案件信息；否则需手动将案件信息补充完整后再办理，或将案卷包导入后再办理。
