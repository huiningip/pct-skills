# 附录C：PATENTSCOPE 检索系统用户指南（WIPO官方，2024年1月）— 速查版

> 来源：WIPO《PATENTSCOPE 用户指南》（2024年1月版，83页）。本章为结构化速查版；界面与最新功能以官方指南为准（系统持续迭代，本指南截图反映 2024-01 样式）。

**一、系统定位**
- PATENTSCOPE 是 WIPO 免费提供的专利检索系统，可查阅数百万份**专利文献**与**非专利文献（NPL，来自 IEEE/Nature/Wikipedia/MDPI 开放获取内容）**。
- 覆盖范围：PCT 国际申请 + 约 50 个参与国/地区主管局的国家/地区文献（含中国、EPO、USPTO、JPO、KIPO、ARIPO、EAPO、OAPI 等）。
- **所处阶段**：国际阶段检索/查询系统（检索 PCT 国际申请、查看 ISR/WOSA、浏览国际公布）。其中的"国家阶段"仅为其数据视图选项卡，非国家阶段程序指南（见"十一、边界说明"）。

**二、五种检索方式（检索菜单）**

| 方式 | 适用场景 | 要点 |
|------|----------|------|
| 1. 简单检索（默认） | 快速查编号/人名/公司/分类号/公布日 | 7 个预设字段：首页、任意字段、全文、识别符/编号、国际分类、名称、公布日 |
| 2. 高级检索 | 复杂/专家查询 | 用**域代码 + 布尔/位置/范围运算符**；词根提取默认开启 |
| 3. 字段组合 | 多概念组合（如日期+发明人、发明人+公司） | 预设字段任意组合；支持"空白字段"查缺失信息（如查无 IPC 的申请） |
| 4. CLIR 跨语言检索 | 扩大多语种覆盖 | 输入 1 种语言关键词→同义词+13 语种译文扩展；可选自动/监督模式、查准/查全 |
| 5. 化学结构检索（需登录） | 化学信息 | 转换结构/结构编辑器/上传结构/子结构检索；Markush（枚举式+匹配算法）；单次最多选 1024 种化合物 |

**三、常用域代码（高级检索）**
- 文本：`EN_TI`(英标题) `EN_AB`(英摘要) `EN_DE`(英说明书) `EN_CL`(英权利要求) `EN_ALLTXT`(英全文=标题+摘要+说明书+权利要求)；其他语种前缀 `FR_`/`DE_`/`ZH_`/`JA_`/`KO_` 等。
- 当事人：`IN`(发明人) `PA`(申请人/受让人)。
- 日期/编号：`DP`(公布日) `AP`(申请日/号) `PN`(公布号)。
- 分类：`IC`(IPC，自动含小组) `IC_EX`(精确 IPC，支持 `*`) `CPC` `CLASSIF`(IPC+CPC 组合) `FICLASSIF`(日本 FI)。
- 化学：`ENUM`(枚举 InChIKeys) `MN`(Markush 编号，科睿唯安)。
- 非专利文献 NPL：`AU`(作者) `JO`(期刊) `PU`(出版者) `DTY:NPL`(全部 NPL 记录) `CTR:ZZ`(仅限 NPL)。
- 完整域代码列表（官方，动态更新）：https://patentscope.wipo.int/search/en/help/fieldsHelp.jsf

**四、检索句法速查（高级检索）**
- 布尔（须大写）：`AND` `OR` `NOT` `ANDNOT`。
- 通配符：`*`（词中/词尾 0+ 字符，不支持前导；每查询≤50、每字段≤10）；`?`（单字符；非登录≤3、登录≤7）。
- 位置：`NEAR`（默认间距 5 词）、`BEFORE`（A 在 B 之前）。
- 模糊：`~`（如 `roo~` → room/roof/root）。
- 加权：`^`（如 `power^ nuclear`，提升 power 权重）。
- 过滤：`+`(要求) / `-`(禁止)。
- 范围：`[.. TO ..]`(含两端) `{.. TO ..}`(不含两端)。
- 分组：`( )` 用于子查询。
- 句法详情：https://patentscope.wipo.int/search/en/help/querySyntaxHelp.jsf

**五、专利族（PATENTSCOPE 专利族）**
- 定义：不同主管局就同一发明的不同公布分组，含 PCT 途径与巴黎途径；PCT 专利族为其子集。
- **纳入标准代码**（标注为 `IC` 系列，显示在专利族选项卡申请日下方；⚠️ 此 `IC` 系列与上方"IPC 分类域代码 `IC`"同名但含义不同，勿混淆）：
  - `IC`：已公布的 PCT 申请（= 专利族起源 + 国家阶段选项卡信息）
  - `IC`：PATENTSCOPE 中已公布且已进入国家阶段的 PCT 申请
  - `IC`：未纳入 PATENTSCOPE 但已公布且进入国家阶段的 PCT 申请
  - `IC`：与另一美国申请相关的美国申请
  - `IC`：本族申请的首次且唯一优先权
  - `IC`：按优先权字段连接
  - `IC`：与同局另一申请有关的国家申请（分案/续案/再公告等）
- 提示：代码表示"首先符合"的标准，非唯一符合标准（如标 `IC` 的进入国家阶段申请亦符合 `IC`）。

**六、分类检索**
- IPC：每年 1 月 1 日新版生效；`IC:` 按等级/词法含小组（勿加 `*`）；精确匹配用 `IC_EX:`（可加 `*`）。
- CPC：EPO 与 USPTO 联合体系（2013 起）；字段 `CPC` / `CLASSIF`；PATENTSCOPE 含超 2.9 亿 CPC 条目，每日更新。
- FI（文档索引分类）：日本体系，依 IPC；字段 `FICLASSIF`（如 `FICLASSIF:("GG*")`）。

**七、浏览菜单（无需检索，按集合浏览）**
- 按星期浏览（PCT）：WIPO 每周四公布新 PCT 申请；可下载 Excel、查 IPC 统计（近 13 周趋势图）。
- 公报档案：1978 年以来全部 PCT 申请可检索官方列表。
- 序列表：已公布 PCT 申请的核苷酸/氨基酸序列表（按年份+公布周）。
- 进入国家阶段 完整下载 / 增量下载（最近7天）：下载进入国家阶段的申请数据。
- 规范文件：下载标准 ST / 本年度 / 全部（1978 起）官方 PCT 出版物。

**八、检索结果与单条记录详情**
- 结果列表优化：文献汇编（专利局）、检索语言、词根提取开关、按专利族分组、含 NPL；登录用户可下载最多 10,000 条（Excel）；可生成 RSS 源监测。
- 单条记录选项卡：
  - **PCT 著录项目数据**：文件识别、国内/优先权/公布/分类数据。
  - **说明书 / 权利要求书**：含集成机器翻译。
  - **附图**：直接查看。
  - **ISR/WOSA**：国际检索报告 / 国际检索单位书面意见。
  - **国家阶段**：进入日与国家参考编号（由相关国家局提供）。
  - **专利族 / 通知 / 文件 / 化合物** 等。
- **PCT 监测**（需登录）：在 PCT 著录项目选项卡点"加入关注"，于 WIPO 账户"已关注申请"中查看；最多监测 20 件；变更（新文件、国家阶段信息、著录更新、再公告）高亮提示。

**九、工具**
- WIPO Translate：神经机器翻译，16 个语言对（含中英、日英、韩英、俄英等），按 IPC 32 个技术领域训练。
- WIPO Pearl：多语术语门户（10 语种，专家验证），可概念图搜索并导出至 PATENTSCOPE 组合检索。
- IPC 绿色清单：无害环境技术（EST）集中检索。
- 专利登记簿门户：核实专利/SPC 法律状态。
- 应对新冠专题：相关专利情报汇编。

**十、登录与设置**
- 免费 WIPO 账户权益：化学结构检索、NPL 下载、结果列表下载（≤10,000）、保存查询（取消"私人查询"勾选可共享并启用 RSS）、多文档下载、简单检索选专利局等。
- 设置项：查询（默认语言/词根/排序）、专利局（文献汇编）、结果（显示域/分析呈现）、下载、界面（默认检索界面、Google 翻译）。

**十一、边界说明（重要）**
- PATENTSCOPE ≠ **ePCT**：前者是公开检索/查询数据库，后者是 PCT 国际阶段**提交与办理门户**（属 `pct-administrative` 管辖）。二者不可混用。
- PATENTSCOPE 的"国家阶段"选项卡/下载仅为**数据视图**（数据来自各参与局），并非国家阶段进入程序指南；进入国家阶段的手续/期限/译文见 `pct-national-phase`。
- ISR/WOSA 查看属国际检索阶段产出（联动本技能第4章 国际检索）；国际公布浏览（按星期/公报档案）属国际公布阶段。
- 动态维护：指南为 2024-01 版，PATENTSCOPE 界面与功能持续更新，使用前以官方最新指南/帮助为准。
