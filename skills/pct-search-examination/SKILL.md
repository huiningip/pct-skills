# PCT国际检索与初步审查指南

## 角色

本技能是 **PCT 国际检索与初步审查标准子技能**，隶属 `pct-guide` 母技能。对应《PCT国际检索和初步审查指南》(ISPE)，面向国际检索单位（ISA）和国际初步审查单位（IPEA）的审查操作，同时作为申请人/代理人理解审查标准、解读 ISR/WO/ISA/IPER 的权威参考。

## 任务

- 按审查要素定位 ISPE 对应部分/章节并输出审查标准。
- 完成「PCT条约 + 实施细则 + ISPE指南」三重引用验证。
- 提供发明单一性判断（STF 原则 + 48 个示例导向，编号 1–48）。
- 提供三性（新颖性/创造性/实用性）国际审查标准（Art.33 问题-解决法）。
- 解读引文分类（X / Y / A / P / O / T / E / D / L / &，共 9 类）与 PCT 最低文献范围。
- 指导 WO/ISA 与 IPER 栏目填写规范。
- 提供国际初步审查程序（第 II 章）与质量框架（10 要素）要点。
- 借助 PATENTSCOPE 支持现有技术检索。
- 向用户交付**符合输出格式规范**的分析结论。

## 上下文（背景数据）

- 依据《PCT国际检索和初步审查指南》(ISPE)：文件编号 PCT/GL/ISPE/14，生效日期 2026 年 1 月 1 日（取代 PCT/GL/ISPE/13）。
- **8部分22章**：Part I 引言概述(1-3) → Part II 申请内容(4-8) → Part III 审查标准(9-14) → Part IV 检索(15-16) → Part V 书面意见/IPER(17) → Part VI 初步审查程序(18-20) → Part VII 质量框架(21) → Part VIII 行政程序(22)。
- **适用对象**：ISA 审查员（检索操作和书面意见）、IPEA 审查员（国际初步审查程序）、申请人/代理人（理解审查标准、预判审查意见）、专利从业者（解读 ISR/WO/ISA/IPER）。
- **核心标准**：新颖性 = 不是已知技术的一部分（Art.33(2)）；创造性 = 考虑现有技术、非显而易见（Art.33(3)，问题-解决法）；工业实用性 = 可在工业中制造或使用（Art.33(4)）。
- **发明单一性**：48 个示例指导判断（Part III Ch.10，2026 版 ISPE/14，编号 1–48），核心 = 相同或相应的特定技术特征（STF）。
- **联动**：`pct-international-phase`（申请人视角的检索/审查操作）；`pct-administrative`（最低文献 Annex H、表格）；涉及国家阶段审查标准时转 `patent-exam-pct-national` 或 `patent-exam-substantive`。

## 流程（步骤）

1. **确定审查阶段**：国际检索（第 I 章）还是初步审查（第 II 章）。
2. **定位审查内容**：对应 ISPE 部分/章节。
3. **引用标准**：完成 PCT 条约 + 细则 + ISPE 指南三重引用。
4. **审查要素检查**：排除主题 / 单一性 / 三性 / 检索 / 书面意见。
5. **输出格式化**：按输出格式规范组织交付文本（法规依据 → 审查标准 → 实务要点 → 版本提示）。

> 🔴 **CHECKPOINT 1**：用户请求涉及 PCT 第 I 章（国际检索）还是第 II 章（初步审查）？确认审查阶段后再定位对应 ISPE 章节，避免引用错误标准。
> 🔴 **CHECKPOINT 2**：审查结论是否已通过三重引用验证（PCT条约 + 实施细则 + ISPE指南）？尤其注意发明单一性（Ch.10）和创造性判断（Ch.13，问题-解决法）的案例匹配。
> 🔴 **CHECKPOINT 3（审查标准前）**：确认涉及的是 PCT Art.33 标准（国际审查标准）还是国家阶段审查标准（如中国 A22.2）。若是国家阶段审查，转至 `patent-exam-pct-national` 或 `patent-exam-substantive`。

## 规则（约束/边界）

1. **I 章 ≠ II 章标准**：第 I 章（国际检索，Art.15-19）仅为检索 + 初步意见；第 II 章（国际初步审查，Art.31-42）才是正式审查。禁止混用。
2. **创造性必用问题-解决法**：严格按三步法——①最接近现有技术 ②客观技术问题 ③显而易见性，禁止跳过直接下结论。
3. **单一性以 STF 为纲**：48 个示例仅为示例（2026 版 ISPE/14 Ch.10，编号 1–48），核心判断标准是 STF（对现有技术整体做出贡献的技术特征）。
4. **引文分类精确使用**：X（单独否定新颖性/创造性）/ Y（结合否定创造性）/ A（背景技术）/ P（中间文献）/ O（非书面公开）/ T（理论文献）/ E（冲突申请）/ **D（申请中已引证文献）/ L（其他理由引证，如质疑优先权）** / &（同族）。共 9 类（ISPE §16.65–16.75）。ISPE §16.65 明确引文分类的法源为《PCT行政规程》**Section 505**（特别相关文献：X／Y）与 **Section 507**（特殊类别：507(a) O ／ 507(b) E ／ 507(c) A ／ 507(d) P ／ 507(e) T ／ 507(f) L；D 见 §16.74），另 Section 503 为引用文献的标识方式。⚠️ **Section 506 在现行 PCT/AI/26 中已删除（[Deleted]）**，不得再引。
5. **互联网公开须可追溯**：须确认发布时间可追溯（如 Wayback Machine 存档、网站发布日期）。
6. **检索须覆盖最低文献**：专利文献 + 非专利文献（NPL）+ 特定技术领域数据库。
7. **PCT 标准 vs 中国标准**：PCT Art.33 为国际通用标准（问题-解决法），与中国 A22.2/A22.3 在表述和细节上有差异，不可等同。
8. **WO/ISA 无约束力但影响大**：对各国无约束力，但对后续国家阶段有显著影响。
9. **输出硬约束（对用户交付文本）**：
   - **严禁输出任何 Markdown 表格**；
   - **如果找不到数据，直接回复"无"，严禁编造**。
10. 本技能内部知识库（参考/指引内容）不受第 9 条"禁表格"约束，可保留 Markdown 表格作为知识载体。

##### 第10章：发明单一性（核心章节，48个示例）

| 判断标准 | 说明 |
|---------|------|
| **一般性原则** | 权利要求之间应包含相同或相应的特定技术特征(same or corresponding special technical features) |
| **STF定义** | 特定技术特征(Special Technical Features)=对现有技术整体做出贡献的技术特征 |
| **案例类型** | 48个示例(2026版ISPE/14，编号1–48)覆盖：产品/方法/用途/组合物/中间产物/化学Markush等多种情形 |

##### 第12章：新颖性标准

| 要素 | ISPE标准(Art.33(2)) |
|------|-------------------|
| **对比原则** | 单独对比：不与多份文献结合 |
| **对比内容** | 全部技术特征；隐含公开的内容 |
| **惯用手段** | 直接置换不具新颖性 |
| **数值范围** | 与在先公开范围重叠→缺乏新颖性 |

##### 第13章：创造性标准（问题-解决法）

```
步骤1: 确定最接近的现有技术
步骤2: 确定要解决的技术问题
步骤3: 判断要求保护的发明对本领域技术人员来说是否显而易见
```

| 考量因素 | 说明 |
|---------|------|
| 最接近现有技术 | 与发明技术领域相同/功能最接近的对比文件 |
| 区别特征+技术问题 | 确定区别特征→对应的技术效果→客观技术问题 |
| 显而易见性 | 现有技术整体上是否存在教导/启示 |
| 辅助因素 | 商业成功/长期需求/预料不到的技术效果 |

##### 引文分类系统

| 分类 | 含义 | 使用场景 |
|------|------|---------|
| **X** | 特别相关的文献 | 单独使用即可否定新颖性或创造性 |
| **Y** | 特别相关的文献（组合） | 与其他文献结合可否定创造性 |
| **A** | 背景技术文献 | 一般技术背景 |
| **P** | **中间文献** | 公布日落在**优先权日与国际申请日之间**的文献（含与最早优先权日同日公布者）；须与 X/Y/A 组合标注（P,X ／ P,Y ／ P,A）—— ISPE §16.71 |
| **O** | 非书面公开 | 口头公开/使用/展览等；须与 X/Y/A 组合标注（O,X ／ O,Y ／ O,A）—— ISPE §16.70 |
| **T** | **理论／原理文献** | 公布日晚于申请日或优先权日，但有助于理解发明所依据的原理或理论，或用以表明发明的推理／事实有误 —— ISPE §16.72 |
| **E** | **潜在冲突的专利文献** | 申请日或优先日早于本申请的国际申请日、但在国际申请日当日或之后公布的文献（依 Rule 33.1(c)）；可组合 E,X ／ E,Y ／ E,A —— ISPE §16.73 |
| **D** | **申请中已引证的文献** | 说明书或检索报告中已引用的文献；须与 X/Y/A 组合标注（D,X ／ D,Y ／ D,A）—— ISPE §16.74 |
| **L** | **其他理由引证** | 如用以质疑优先权主张（巴黎公约 Art.4(C)(4)）、或确立另一引证的公布日等证据性引用 —— ISPE §16.75 |
| **&** | **同一专利族文献** | 相同发明在不同国家／地区的公布 |

### 关键审查标准速查

| 审查要素 | PCT Art.33标准 | ISPE指南章节 |
|---------|---------------|-------------|
| 新颖性 | 不是已知技术的一部分 | Ch.12 |
| 创造性 | 考虑现有技术，非显而易见 | Ch.13(问题-解决法) |
| 工业实用性 | 可在工业中制造或使用 | Ch.14 |
| 充分公开 | 清楚完整，使本领域能实施 | Ch.4 |
| 权利要求支持 | 以说明书为依据，清楚简要 | Ch.5 |
| 单一性 | 包含相同或相应STF | Ch.10(48个示例) |

### 实务要点

1. **PCT审查标准 vs 中国审查标准差异**：PCT Art.33 的新颖性/创造性标准为国际通用标准，与中国《专利法》A22.2/A22.3 的审查标准在表述和具体适用上有一定差异，尤其创造性判断三步法（ISPE 采用问题-解决法，中国审查指南也使用三步法但细节不同）。
2. **WO/ISA的参考价值**：虽然对各国无约束力，但 WO/ISA 的否定意见对后续国家阶段有显著影响，可在第 II 章或国家阶段进行争辩。
3. **补充检索策略**：当主要 ISA 未检索到关键文献或技术领域特殊（如生物/化学）时，补充检索很有价值。
4. **IPER的时机**：收到 WO/ISA 后如认为有说服空间，及时（22 个月内）提交第 II 章要求书，可在 IPER 中纳入申请人意见。
5. **互联网公开的认定**：ISPE 对互联网公开的日期认定有详细规则（Ch.11），明确网络发布时间作为现有技术日的认定标准。

### 失败模式与恢复

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 发明单一性判断不准确(48个示例中找不到对应情形) | 回到基本原则(STF定义)→比对最接近案例类型 | 参考ISPE Ch.10一般性原则→适用最宽泛解释 |
| WO/ISA栏III(三性)填写与ISA标准不一致 | 对照ISPE Ch.12-14逐项核对新颖性/创造性/实用性标准 | 参考同ISA过往WO/ISA范本→确保一致性 |
| 创造性判断中问题-解决法步骤混淆 | 严格按照Ch.13三步法：①最接近现有技术②客观技术问题③显而易见性 | 参考中国三步法(审查指南第二部分)作为辅助标准 |
| 互联网公开的现有技术日期认定困难 | 依据ISPE Ch.11详细规则→核验发布时间和可追溯性 | 指定公开日期+说明可信度(如网页存档Wayback Machine) |
| 补充检索(SISA)结果与主ISA检索冲突 | 综合分析两份检索→标注引文冲突点 | 优先采用最早或最全面的检索结果，附注说明差异 |
| 书面意见被申请人质疑后需复查 | 回查ISPE Ch.17栏位填写规范→确认意见有据可依 | 若意见有误→及时更正并通知申请人；若无误→准备理由说明 |
| 质量框架内部审查发现问题 | 对照10大质量管理要素逐项改进 | 纳入持续改进计划→下轮审查重点跟踪 |
| 审查时遗漏PCT最低文献(非专利文献)检索 | 核查ISPE Part IV Ch.15最低文献范围→补充NPL数据库检索 | 补充检索后更新ISR→附注说明新增检索的范围和日期 |
| 优先权有效性审查未发现优先权文件与申请不一致 | 逐项核对在先申请文件与PCT申请的一致性(权利要求支持/新增内容) | 优先权部分无效→保留有效部分→标出无效部分的优先权日失效后果 |
| 说明书充分公开判断与申请人/代理人产生分歧 | 引用ISPE Ch.4标准(本领域技术人员能否实施)→逐项分析公开程度 | 分歧无法解决→在书面意见中保留条款(Art.17(2))→标注缺陷类型 |

### 禁止行为与反例

| # | 禁止行为 | 原因 | 正确做法 |
|---|---|---|---|
| 1 | 将I章检索标准等同于II章审查标准 | 第I章(国际检索,Art.15-19)仅为检索+初步意见；第II章(国际初步审查,Art.31-42)才是正式审查 | 明确用户请求的阶段→输出对应ISPE章节(Part IV vs Part VI) |
| 2 | 创造性判断跳过问题-解决法直接下结论 | ISPE Ch.13明确规定创造性须采用问题-解决法三步判断 | 严格按步骤操作：①最接近现有技术②客观技术问题③显而易见性→引案例佐证 |
| 3 | 发明单一性判断仅依据案例而不理解STF原则 | 48个示例仅为示例(2026版ISPE/14，编号1–48)，核心判断标准是STF(特定技术特征) | 先理解STF原则(对现有技术做出贡献的特征)→再匹配最接近案例类型 |
| 4 | X/Y/A引文分类使用不当 | 引用分类不当会导致审查意见可靠性受损 | 严格按Ch.16引文分类标准：X(单独否定新颖性/创造性)/Y(结合否定创造性)/A(背景技术) |
| 5 | 互联网公开不考虑日期可追溯性 | ISPE Ch.11要求确认公开日期的准确性和可追溯性 | 引用互联网公开时需附发布时间证据(如Wayback Machine存档、网站发布日期) |
| 6 | 书面意见栏II填写不规范(排除客体/单一性/公开) | 栏II的填写标准有详细规范(ISPE Ch.17)，填写不全影响意见权威性 | 按栏II格式逐项填写：排除客体→单一性→充分公开→如有缺陷标注对应规则 |
| 7 | 检索策略未覆盖PCT最低文献的全部范围 | ISPE Part IV Ch.15要求检索覆盖专利文献+非专利文献(NPL)+特定技术领域数据库 | 制定检索策略时列出所有需覆盖的数据库→按优先级排序→记录检索式 |
| 8 | IPER中引用ISR未涵盖的新文献但未说明理由 | IPER可引用新文献，但须说明该文献在ISR阶段未被引用的原因 | 引用新文献时附注说明：ISR阶段未检索到→IPEA补充检索中发现 |
| 9 | 交付文本使用 Markdown 表格 | 违反输出格式硬约束 | 用标题 + 列表组织交付文本 |
| 10 | 数据缺失时编造或推测 | 违反"无数据回'无'"硬约束 | 直接回复"无"，并提示可补充的检索途径 |
